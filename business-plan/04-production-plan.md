# 4. Производственный план и оборудование

## 4.1. Бочковые бани — спецификация

### Выбор модели

На основе анализа фотоматериалов проекта выбрана модель бочковых бань **премиум-класса** с чёрной битумной кровлей, деревянными фасадами и дымоходами:

| Параметр | Значение |
|---|---|
| Тип | Баня-бочка «Викинг» / «Квадро-овал» |
| Длина | 4 000–4 500 мм |
| Диаметр / ширина | 2 200–2 400 мм |
| Высота | 2 200–2 500 мм |
| Внутренняя площадь | 8–10 м² |
| Материал корпуса | Термомодифицированная ель / кедр |
| Кровля | Битумная черепица (чёрная) |
| Утепление | Минеральная вата 50 мм (для круглогодичного использования) |
| Вместимость | 4–6 человек |

### Внутренняя планировка каждой бани

### Комплектация каждой бани

| Позиция | Описание |
|---|---|
| Корпус | Термодревесина, обручи нержавеющая сталь |
| Печь дровяная | Тип «Ферингер» или TMF (мощность 8–12 кВт) |
| Дымоход | Нержавеющая сталь, двустенный, с дефлектором |
| Полки | 2 яруса, термолипа / абаши |
| Дверь | Стеклянная термостойкая (8 мм закалённое стекло) |
| Окно | Круглое «иллюминатор», диаметр 350 мм |
| Подставка | Металлические опоры / лаги на бетонных блоках |
| Ступени | Металлическая лестница с деревянными накладками |
| Козырёк | Входной навес с битумной черепицей |

## 4.5. Технологический процесс обслуживания

### Цикл одного сеанса

```
09:00  Администратор открывает комплекс
       ↓
09:00  Банщик начинает протопку бани №1 (на 10:00)
       ↓
10:00  СЕАНС 1 — Гости в бане №1 (2–3 часа)
       ↓
12:30  Гости уходят → Уборка (30 мин) → Протопка (40 мин)
       ↓
13:40  СЕАНС 2 — Следующие гости
       ↓
  ...  (повторяется 4–5 раз в день на каждую баню)
       ↓
23:00  Последние гости уходят
       ↓
23:30  Уборка, тушение огня, закрытие
```
