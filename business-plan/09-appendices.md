# 9. Приложения

## Приложение А. Чек-лист открытия бизнеса

### Этап 1: Документация (месяц 1)

- [ ] Регистрация ИП (через Госуслуги или МФЦ)
- [ ] Выбор ОКВЭД: 96.04 (основной), 96.02, 93.29, 56.10 (дополнительные)
- [ ] Выбор системы налогообложения: УСН 6%
- [ ] Открытие расчётного счёта
- [ ] Заказ электронной подписи (КЭП)
- [ ] Регистрация в ФСС (при найме сотрудников)
- [ ] Подача уведомления в Роспотребнадзор о начале деятельности

### Этап 2: Земельный участок (месяц 1–2)

- [ ] Мониторинг torgi.gov.ru на предмет свободных участков в Сочи
- [ ] Подача заявления в Департамент имущественных отношений
- [ ] Участие в аукционе / подача заявки без торгов (для МСП)
- [ ] Заключение договора аренды (срок: 10 лет)
- [ ] Регистрация договора в Росреестре
- [ ] Заказ топографической съёмки участка

### Этап 3: Коммуникации (месяц 2–3)

- [ ] Подача заявки на технологическое присоединение (электричество, 30 кВт)
- [ ] Бурение скважины / подключение к центральному водопроводу
- [ ] Устройство септика / подключение к канализации
- [ ] Установка электрического щита, счётчика
- [ ] Проверка качества воды (анализ в СЭС)

### Этап 4: Закупка и монтаж (месяц 2–3)

- [ ] Выбор производителя бочковых бань
- [ ] Заказ 5 бочковых бань с полной комплектацией
- [ ] Заказ печей (если не в комплекте)
- [ ] Приёмка и проверка бань на производстве (желательно)
- [ ] Организация доставки
- [ ] Подготовка площадок для установки (бетонные блоки / лаги)
- [ ] Монтаж и установка бань
- [ ] Монтаж дымоходов
- [ ] Пусконаладочные работы (пробная протопка)

### Этап 5: Благоустройство (месяц 3–4)

- [ ] Мощение дорожек (тротуарная плитка)
- [ ] Устройство костровой площадки
- [ ] Установка скамеек вокруг костра
- [ ] Гравийная отсыпка
- [ ] Укладка газона
- [ ] Посадка кустарников / деревьев
- [ ] Монтаж освещения (LED-гирлянды, фонари)
- [ ] Установка хозяйственного блока (модульный контейнер)
- [ ] Оборудование ресепшн
- [ ] Установка биотуалетов / сантехники
- [ ] Монтаж системы видеонаблюдения
- [ ] Установка вывески и навигации

### Этап 6: Согласования (месяц 3–4)

- [ ] Получение заключения СЭС (Роспотребнадзор)
- [ ] Получение заключения пожарной инспекции (МЧС)
- [ ] Заключение договора на вывоз ТКО
- [ ] Оформление медицинских книжек для персонала
- [ ] Страхование имущества и ответственности
- [ ] Приобретение и регистрация онлайн-кассы

### Этап 7: Персонал (месяц 3)

- [ ] Размещение вакансий (HeadHunter, Avito, локальные группы)
- [ ] Собеседования и отбор кандидатов
- [ ] Оформление трудовых договоров
- [ ] Оформление медицинских книжек
- [ ] Обучение персонала (технология протопки, сервис, ПБ)
- [ ] Проведение инструктажей по ОТ и ПБ

### Этап 8: Маркетинг (месяц 3–4)

- [ ] Разработка сайта (лендинг + бронирование)
- [ ] Создание аккаунтов в соцсетях (VK, Telegram)
- [ ] Профессиональная фотосессия объекта
- [ ] Размещение на Яндекс.Картах и 2ГИС
- [ ] Регистрация на агрегаторах (gosha.travel, tripster)
- [ ] Печать рекламных материалов (флаеры, визитки)
- [ ] Договоры с отелями / туроператорами на размещение рекламы
- [ ] Приглашение блогеров на тестовое открытие

### Этап 9: Запуск (месяц 4–5)

- [ ] Тестовое открытие (мягкий запуск)
- [ ] Сбор обратной связи, доработка процессов
- [ ] Полноценное открытие
- [ ] Запуск рекламных кампаний
- [ ] Мониторинг отзывов и оперативная реакция

## Приложение Б. Необходимые документы для администрации Сочи

### Пакет документов для аренды муниципальной земли

1. **Заявление** о предоставлении земельного участка в аренду (типовая форма)
2. **Копия паспорта** ИП
3. **Свидетельство о регистрации ИП** (или лист записи ЕГРИП)
4. **ИНН**
5. **Бизнес-план** (данный документ)
6. **Эскизный проект** размещения объектов на участке
7. **Справка об отсутствии задолженности** перед бюджетом
8. **Выписка из ЕГРИП** (не старше 30 дней)

### Пакет документов для Роспотребнадзора

1. Уведомление о начале деятельности (форма утверждена ПП РФ №584)
2. Договор аренды земельного участка
3. Программа производственного контроля
4. Протоколы лабораторных исследований воды
5. Медицинские книжки персонала
6. Договор на вывоз ТКО
7. Договор на стирку / дезинфекцию текстиля

### Пакет документов для МЧС (пожарная безопасность)

1. Декларация пожарной безопасности
2. Приказ о назначении ответственного за ПБ
3. Инструкции о мерах пожарной безопасности
4. Журнал инструктажей по ПБ
5. Акт проверки и испытания огнетушителей
6. План эвакуации (для хозблока)
7. Сертификаты на печи и дымоходы
