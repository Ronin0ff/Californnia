# ProfitPilot AI — Оптимизатор юнит-экономики в реальном времени

Коммерческая SaaS-платформа для продавцов на маркетплейсах **Wildberries** и **Ozon**.

## Возможности

- Калькулятор юнит-экономики с учётом всех скрытых издержек
- AI-рекомендации по ценообразованию
- Автоматический репрайсер
- Рекламный биддер
- Мониторинг конкурентов
- Работа по SKU/артикулу без обязательного API
- Интеграция с API WB и Ozon

## Тарифы

| | Стандарт | Pro | Enterprise |
|---|---|---|---|
| Цена | 2 500 ₽/мес | 4 990 ₽/мес | 19 990 ₽/мес |
| SKU | До 10 | До 50 | Безлимит |
| Маркетплейсы | WB + Ozon | WB + Ozon | WB + Ozon |

## Технологии

- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- **Backend**: MetaGPTx Web SDK (BaaS)
- **Платежи**: ЮKassa
- **Деплой**: Vercel

## Запуск

```bash
pnpm install
pnpm dev
```

## Деплой на Vercel

```bash
pnpm build
# vercel --prod
```
